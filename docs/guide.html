一、安装与首次启动

系统要求

  • Windows 10 1809 或 Windows 11（x64）
  • 内存 4 GB 及以上
  • 无需预装 Java 或任何运行环境

安装步骤

  1. 从 Releases 页面 下载 LePlayer-Setup.exe
  2. 右键安装包 → 以管理员身份运行（安装到 Program Files 需要权限）
  3. 选择安装路径，跟随向导完成
  4. 首次启动会引导你添加音乐文件夹
升级提示：直接运行新版安装包覆盖安装即可，音乐库、设置、歌单全部保留。

单实例保护

LePlayer 同时只能运行一个实例。如果已有程序在运行，再次启动会直接退出（不会弹出错误窗口）。

二、音乐库管理

添加音乐文件夹

  • 进入 设置 → 音乐文件夹，点击"添加文件夹"
  • 选择存放音乐的目录，支持多级子文件夹递归扫描
  • 添加后自动开始扫描，进度可见

支持格式

MP3 / FLAC / WAV / AAC / OGG / OPUS / M4A / WMA 等常见格式均支持。

增量扫描

  • 扫描基于文件修改时间和大小，未变化的文件不会重复解析
  • 新增文件只需重新扫描新增部分，万级曲库也能秒级完成
  • 在设置中可手动触发"重新扫描"

文件去重

LePlayer 会自动识别内容相同的文件（基于内容哈希），重复文件不会重复入库。

元数据

  • 自动读取歌曲标签（标题、艺术家、专辑、封面、曲风）
  • 文件名方向自动判断：自动识别"歌手-歌名"还是"歌名-歌手"格式
  • 自动清理标签中的脏值（如艺术家字段写着"日语""纯音乐"等）
  • 在线元数据补全静默执行，不打断你的操作

三、播放控制

基础操作

操作方式
播放/暂停空格键，或点击播放栏按钮
上一首/下一首播放栏按钮，或 Ctrl + ← / →
进度跳转拖动播放进度条
音量播放栏音量滑块，或 Ctrl + ↑ / ↓
双击播放歌曲列表中双击任意歌曲开始播放
右键菜单播放 / 收藏 / 添加到歌单 / 从列表删除 / 彻底删除源文件

播放模式

  • 顺序播放：按列表顺序播放，播完停止
  • 循环列表：播完最后一首回到第一首
  • 单曲循环：重复当前歌曲
  • 随机播放：随机打乱播放顺序

四、音频输出

两种输出模式

模式说明适用场景
共享模式系统混音，可与其他应用同时发声日常听歌、边工作边听
独占模式直通声卡，bit-perfect，其他应用静音专注聆听、高保真回放

采样率自适应

  • 开启后，LePlayer 会自动检测音频文件的采样率
  • 如果文件采样率与设备原生采样率一致，跳过重采样，零音质损失
  • 不一致时使用高质量重采样算法，防过冲削波
注意：独占模式下音量由系统音量控制（应用内音量滑块无效），这是 WASAPI 独占模式的正常行为。

五、桌面歌词

开启歌词

  • 播放时按 Ctrl + L，或右键托盘图标 → 显示桌面歌词
  • 自动读取内嵌歌词和同名 .lrc 文件
  • 支持逐字卡拉OK高亮，逐行跟随播放进度

歌词窗口操作

操作效果
拖动窗口自由移动歌词位置
点击小锁图标锁定位置，锁定后鼠标点击穿透到下层窗口
再次点击锁图标解锁，可以拖动调整位置
点击歌词文字解锁后可点击切歌
锁定穿透：锁定歌词后，歌词窗口不会再挡住你打字或点击其他软件。解锁后恢复正常交互。锁图标默认半透明，鼠标悬停时高亮显示。

六、迷你模式

  • 点击主窗口右上角的迷你模式按钮，切换到紧凑小播放器
  • 只保留封面、歌曲名和播放控制按钮
  • 再点一次恢复完整窗口

七、歌单管理

创建歌单

  • 左侧边栏点击"+"按钮，输入歌单名即可创建
  • 在"添加到歌单"对话框中也可输入新歌单名
  • 歌单自动保存到数据库，重启不丢失

添加歌曲

  • 右键歌曲 → 添加到歌单 → 选择目标歌单
  • 支持批量选择（Ctrl/Shift + 点击）后批量添加
  • 可将整个文件夹、专辑、艺术家批量加入歌单

整理歌单

  • 歌单内支持拖动排序
  • 右键歌单可重命名、删除
  • 从歌单删除不会删除源文件

八、主题与外观

深浅主题

  • 自动跟随系统主题（Windows 明暗切换自动响应）
  • 可在设置中手动锁定浅色或深色
  • 动态取色：根据专辑封面自动调整界面配色

任务栏与托盘图标

  • 任务栏图标随主题深浅自动切换
  • 系统托盘图标同样跟随主题
  • 关闭主窗口时最小化到托盘（可在设置中改为直接退出）

九、全局快捷键

快捷键功能
Ctrl + Alt + ←上一首
Ctrl + Alt + →下一首
Ctrl + Alt + 空格播放/暂停
媒体键播放/暂停、上一首、下一首（键盘上的多媒体按键）
全局快捷键在任何应用中都生效，即使 LePlayer 在后台也能控制播放。

十、系统托盘

  • 关闭主窗口默认最小化到托盘，不退出程序
  • 托盘右键菜单：显示主窗口 / 显示桌面歌词 / 播放暂停 / 下一首 / 退出
  • 首次关闭窗口会询问"最小化到托盘还是直接退出"，勾选"不再询问"后记住你的选择

关闭行为

首次关闭主窗口时会弹出选择：最小化到托盘 / 直接退出。勾选"不再询问"后，后续按你的选择执行。所有设置在退出时自动保存，重启后不丢失。

十二、进阶技巧

删除文件保护

  • 右键歌曲 → "彻底删除源文件"会删除磁盘上的文件
  • 首次执行会弹出确认提示，勾选"不再询问"后记住选择
  • 从列表删除只移除数据库记录，不删文件

智选引擎

  • 基于你的播放记录和跳过行为自动推荐相似歌曲
  • 越听越准，不需要手动设置偏好
  • 支持生成分享卡片

离线使用

  • 所有音乐库数据本地存储，不依赖云服务
  • 封面缓存本地保存，离线可看
  • 在线补全仅在需要时联网，不收集使用数据

十三、常见问题

Q: 独占模式下音量调节无效？

A: WASAPI 独占模式下，应用内音量滑块失效，音量由系统音量控制。这是正常行为，切回共享模式即可恢复应用内音量控制。

Q: 全局快捷键没反应？

A: 请确认没有其他软件（如某些输入法、截图工具）占用了相同的全局快捷键。LePlayer 的快捷键是 Ctrl+Alt+方向键/空格，通常不会冲突。

Q: 桌面歌词挡住了打字？

A: 点击歌词窗口左上角的小锁图标锁定位置，锁定后鼠标点击穿透到下层窗口，不影响你打字。再次点击解锁。

Q: 扫描很慢？

A: 首次扫描需要读取所有文件标签，速度取决于磁盘速度。后续扫描是增量的，只处理新增和修改过的文件，会快很多。

Q: 设置重启后不生效？

A: v1.5.4 已修复此问题。所有设置在退出时自动写入磁盘。如果仍有问题，请通过 Issues 反馈。

Q: 支持哪些格式？

A: MP3 / FLAC / WAV / AAC / OGG / OPUS / M4A / WMA 等主流格式。AAC 和 ALAC 无损也支持。
