使用指南

快速上手

添加音乐

首次启动后进入 设置 → 音乐文件夹，添加你的音乐目录，支持 MP3 / FLAC / WAV / AAC / OGG 等格式。

桌面歌词

播放时右键托盘图标 → 显示桌面歌词；点击小锁图标锁定位置，锁定后穿透不挡鼠标。

独占模式

设置中开启 WASAPI 独占，获得 bit-perfect 输出（音量由系统控制）。

快捷键

空格 播放/暂停 · Ctrl + 方向键 切歌 · Ctrl + L 显示/隐藏桌面歌词
