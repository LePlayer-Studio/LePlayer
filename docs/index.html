使用指南

快速上手

开始使用

  • 首次启动后，进入 设置 → 音乐文件夹，添加你的音乐目录
  • 等待扫描完成，歌曲会自动入库，支持 MP3 / FLAC / WAV / AAC / OGG 等格式
  • 双击歌曲开始播放，单击选中，右键打开操作菜单

常用操作

  • 桌面歌词：播放时右键托盘图标 → 显示桌面歌词；点击小锁图标可锁定位置，锁定后穿透不挡鼠标
  • 迷你模式：主窗口右上角切换，只保留小播放器
  • 独占模式：设置中开启 WASAPI 独占，获得 bit-perfect 输出（音量由系统控制）
  • 歌词：自动匹配内嵌歌词和同名 .lrc 文件，支持逐字卡拉OK高亮
  • 智选引擎：基于你的播放记录自动推荐，越听越准
  • 歌单：左侧边栏可新建歌单，右键歌曲 → 添加到歌单

快捷键

  • 空格：播放 / 暂停
  • Ctrl + 方向键：上一首 / 下一首
  • Ctrl + L：显示 / 隐藏桌面歌词
